# Fake GPS

Android-приложение для подмены геолокации на выбранную точку карты. Подходит для разработки и тестирования сценариев, зависящих от местоположения, когда это разрешено владельцем устройства и используемых сервисов.

## Возможности

- выбор точки одним нажатием на карте или перетаскиванием маркера;
- автоматический запуск подмены сразу после выбора точки;
- отправка координат через foreground-службу, в том числе когда приложение свёрнуто;
- остановка подмены из приложения или из постоянного уведомления;
- отображение адреса и координат выбранной точки;
- два источника карты: OpenStreetMap и Esri World Dark Gray Canvas;
- светлая и тёмная темы, интерфейс на русском и английском языках.

## Требования

- устройство с Android 8.0 (API 26) или новее;
- доступ в интернет для загрузки тайлов карты и определения адреса;
- разрешение на доступ к геолокации;
- включённый режим разработчика и выбранное приложение для фиктивных местоположений.

## Как пользоваться

1. Установите и откройте приложение.
2. Разрешите доступ к геолокации.
3. Откройте **Настройки** устройства → **Для разработчиков**.
4. В пункте **Выбрать приложение для фиктивных местоположений** выберите **Fake GPS**. Названия пунктов могут немного отличаться в зависимости от оболочки Android.
5. Вернитесь в приложение и нажмите на нужное место карты. Появится маркер, а подмена координат начнётся автоматически.
6. При необходимости перетащите маркер: новые координаты будут применены после отпускания маркера.
7. Нажмите **Отключить фиктивный GPS** внизу экрана либо **Стоп** в уведомлении, чтобы вернуть обычные источники геолокации.

Пока Fake GPS не выбран в настройках разработчика, приложение покажет инструкцию и не позволит активировать подмену.

## Сборка

Для сборки нужен Android SDK с платформой API 37 и JDK 17 или новее.

```powershell
.\gradlew.bat assembleDebug
```

Готовый APK появится по пути:

```text
app\build\outputs\apk\debug\app-debug.apk
```

Открыть проект также можно в Android Studio и запустить конфигурацию `app` на устройстве или эмуляторе.

## Технологии

| Компонент | Назначение |
| --- | --- |
| Kotlin | код приложения |
| Android SDK | работа с разрешениями, геолокацией и foreground-службой |
| osmdroid | отображение интерактивной карты |
| Gradle | сборка проекта |

## Структура проекта

```text
app/src/main/java/fuck/system/fakegps/
├── MainActivity.kt            # экран разрешений, карта и управление состоянием
├── MockLocationService.kt     # foreground-служба отправки координат
├── MockLocationEngine.kt      # тестовые провайдеры LocationManager
├── MockLocationStore.kt       # сохранение точки и состояния
└── ThemedActivity.kt          # тема и язык интерфейса
```

## Примечания

Координаты обновляются каждые 500 мс для GPS, сетевого провайдера и, на Android 12+, fused provider. Выбранная точка и настройки интерфейса сохраняются между запусками приложения.

При работе службы Android показывает постоянное уведомление. На Android 13 и новее приложение может запросить разрешение на уведомления при первом выборе точки.
